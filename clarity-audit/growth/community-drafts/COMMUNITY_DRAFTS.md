# Community & Social Drafts — HUMAN APPROVAL REQUIRED BEFORE ANY POSTING

Rules: value first, tool second · obey each community's self-promo rules · disclose "I built this" · never duplicate-post the same text · never fake engagement · respond to every genuine reply · if a community says no tools, don't post the tool. Suggested cadence: 1 community/week at launch, only where the human already has (or is willing to first build) a real presence.

## 1 · Reddit (r/smallbusiness / r/EntrepreneurRideAlong style) — data-first
**Title:** I scored my own landing page against a 25-point "5-second test" rubric. It got 41/100. Here's the rubric.
**Body (draft):** Share the *rubric itself* (the 6 categories + top failure patterns from the methodology page), 2–3 things you changed on your own page because of it, what surprised you. Mention the free scanner once at the end ("I turned it into a free checker if you want it automated — mods, remove if not allowed"). Ask: "What would you add to the rubric?"
**Metric:** comments/scan-starts via ?ref=reddit1 · **Risk:** LOW-MED (self-promo rules vary; check each sub sidebar, human decides subreddit).
