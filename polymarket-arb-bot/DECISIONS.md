# Decisions log

Ambiguities and judgement calls made during the autonomous build. Each entry says what was decided and why.

## Process and repository

1. **Branch name.** The brief asked for `feat/polymarket-arb-bot`. The session is bound to
   `arena/f218801c-agents`, and the session rules forbid creating or pushing other branches. All work is on
   `arena/f218801c-agents`. The PR is opened from that branch. Nothing was pushed to `main` or `master`.
2. **Python tooling.** `AGENTS.md` asks for `uv`. The bot's `.venv` was created with `pip` because
   `uv` was not yet available in the environment. `uv` 0.13.1 and `ty` 0.0.89 were then installed into `.venv`.
   Project dependencies are pinned in `pyproject.toml`. `ruff` 0.17.1 and `ty` run from `.venv/bin`.
   Deviation logged. Remedy: `uv sync` in a future session.
3. **Module name.** `types.py` was renamed to `domain.py` because it shadowed the stdlib `types` module.
4. **Repo root `.gitignore` does not list `.env`.** The bot directory has its own `.gitignore`, which lists
   `.env`, `.env.*` (except `.env.example`), `config/LIVE_CONFIRMED*`, `state/*.sqlite*`, `reports/`, and `*.KILL`.
   No `.env` file exists in the tree.
5. **Commits.** Small logical commits: domain, costs, strategies, risk, execution, state, engine and CLI in
   `3e30ccd`; robustness fixes in `6cde38f`; the test suite in `19bc18e`.

## Skills, tools, and third-party code

6. **Repo skill scan.** `tools/skill_router.py plan` suggested `python-testing-patterns`, `temporal-python-testing`
   and `python-code-style`. Their guidance was applied by hand (fixtures, deterministic clocks, hypothesis
   property tests, ruff rules). The skill files were not loaded into the build. Used: test patterns, lint
   conventions. Skipped: Temporal-specific testing (not relevant, no Temporal workflows).
7. **Polymarket SDKs.** The official Python client `py-clob-client` was considered and deferred. Reasons:
   the live path is locked, the sandbox cannot reach the CLOB, and its wallet-signing code would need a full
   audit before use. No wallet SDK is installed. A PyPI package named `polymarket` was rejected as unrelated.
   Signing is not implemented. The live executor requires an injected `Signer`.
8. **Dependency licences** (checked from installed metadata): websockets BSD-3-Clause, httpx BSD-3-Clause,
   httpcore BSD-3-Clause, anyio MIT, h11 MIT, PyYAML MIT, pytest MIT, pytest-cov MIT, pytest-asyncio Apache-2.0,
   ruff MIT, ty MIT, uv MIT/Apache-2.0. **hypothesis is MPL-2.0** (file-level copyleft). It is a dev-only
   dependency and is not shipped, so this is acceptable; flagged for the record.
9. **Wallet-touching code audit.** No third-party code that handles keys is included. The only key-related code is
   our own `execution/clob_auth.py` (L2 HMAC header helpers, with a masked `ApiCredentials.__repr__`) and a
   `Signer` protocol. Both were reviewed by hand. They have not been reviewed by an external auditor, and the

## Data and sources

10. **Sandbox network.** Shell `curl` to Polymarket hosts failed or returned no response. Official docs and
    Gamma/CLOB sample data were retrieved with `fetch_page`. A live WebSocket feed was not consumed. The sandbox
    outbound allowlist covers GitHub, npm, and PyPI only, so no live market-data session was run against
    Polymarket endpoints. This is the reason the paper evidence is replay-based (see REPORT.md).
11. **Recorded fixtures.** No real market recording exists in the workspace. The replay and backtest fixture is
    `tests/fixtures/recordings/synthetic_replay.jsonl`, generated by `tests/fixtures/synth.py`. It is labelled
    synthetic and is not evidence of real-market edge.
12. **Book normalisation.** Bids are sorted descending and asks ascending. Docs examples are inconsistent.
13. **Stale books on reconnect.** After reconnect, a book is unusable until a new snapshot arrives.
14. **Universe is not refreshed during a run.** The universe is loaded at start. Restart to refresh. A limitation.

## Costs and strategies

15. **Fee formula.** `fee = C × rate × p × (1−p)`, rounded UP to 5 dp, taken from the per-market `feeSchedule`.
    The legacy `takerBaseFee` was not used because it did not match `feeSchedule`. A missing fee, a conflicting
    `feesEnabled`, or an `exponent` other than 1 makes the opportunity **INVALID** (never a default).
16. **Gas.** No RPC is reachable from the sandbox. Gas uses a configured fallback (200 gwei, POL $1.00), units are
    conservative, and `source` is reported as `config_fallback`. The gas reserve is subtracted from the
    per-trade notional cap before sizing.
17. **Leg-risk model.** Expected loss = `p_fail (0.05) × Σ unwind losses`. The probability is an assumption.
18. **B1 hold-to-resolution** carries `p_unknown_resolution = 0.5%` of capital, to cover 50/50 or unknown outcomes.
19. **Capital opportunity cost** uses an assumed 4% annual rate on idle USDC. It is not a market quote.
20. **Thresholds.** `min_net_profit_usdc 0.05`, `min_net_pct 0.2%`, `min_annualized_pct 20%`. These are conservative
    defaults chosen by the author, not calibrated.
21. **Minimum order.** Both shares ≥ `min_order_size` and USDC notional ≥ `min_order_size` are enforced.
    The notional check is the conservative reading of the docs.
22. **Strategy A is asks-only (buy the pair, merge).** The brief specifies "using asks". The bid-side
    split-and-sell direction was removed as dead code and is deferred.
23. **Strategy B** has two directions. B1 buys YES in every outcome of an exhaustive group. Exit is `redeem`, with
    resolution haircut and UMA lock-up. B2 is `convert`: buy NO_j, convert, and sell YES_i for i≠j, with exit
    `sell`. Convert follows the official docs (1 NO converts to 1 YES of every other outcome, no collateral). Groups
    with `negRiskOther` or augmented events are skipped, because their Other outcome changes definition.
24. **Spread anomaly guard.** Quoted spread wider than `max_quoted_spread` (0.25) marks the book as anomalous and
    rejects it. This is a judgement call. It can reject legitimate wide markets (documented as a limitation).
25. **Strategies C and D are disabled.** C (cross-market logical) cannot guarantee precision with string-matching
    of resolution criteria, so no logic is shipped. D (cross-venue) needs identical resolution criteria and
    another venue's fees and access rules, which cannot be verified from the sandbox. Both emit nothing and log
    `skipped:<reason>`. Tests verify that they return empty.
26. **Ambiguous resolution** markets are excluded by default (`data.exclude_ambiguous: true`). A manual blacklist
    is `data.blacklist_condition_ids`.
27. **Opportunity IDs** include detection time (`now_ms`). Without it, repeated opportunities on the same market
    were permanently treated as duplicates.

## Execution and risk

28. **Paper execution** re-walks each leg on the overlaid book for the full share count (FOK-style). Any missing,
    stale, unknown, fee-unknown, or insufficient-depth leg cancels all legs with no positions.
29. **Paper overlay** is stamp-based. Simulated consumption persists until the book stamp changes. A TTL overlay was
    tried and removed because it restored consumed liquidity and inflated PnL.
30. **PnL split.** `realized_pnl_usdc` covers merge and sell. Redeem is reported as `expected_pending_resolution`.
    Realised net excludes safety margin and leg risk, as documented.
31. **Partial fills.** A `partial` result engages the kill switch (`unhedged_partial`).
32. **Daily-loss halt** sums all PnL kinds (conservative). It resets at UTC midnight.
33. **Reconciliation** runs every 20 cycles. A mismatch engages the kill switch and logs `reconcile_mismatch`.
34. **Malformed WebSocket frames** are counted and skipped. The affected asset is invalidated, and the session is
    kept. Dropping the whole session on one bad frame was rejected.
35. **`money.dec`** raises `ValueError` for malformed strings. Previously `decimal.InvalidOperation` escaped, found
    by hypothesis fuzzing.
36. **YAML floats** are converted via `str` into `Decimal` (`_dec()`), so config values stay exact.
37. **Live mode is locked.** `LIVE_TRADING=true` AND `config/LIVE_CONFIRMED.txt` are both required. No signer or
    transport ships, so the live executor raises `LiveNotArmed`. The agent did not enable live, did not sign any
    transaction, and did not send any order.
38. **Live order body is incomplete** (no maker, signer, salt, nonce, or feeRateBps fields). `signatureType: 3`
    is unverified. Must be fixed and verified against the current docs before any live use.

## Type checking

39. **`ty` findings** fixed with explicit `isinstance` dispatch (engine, neg-risk vs binary) and narrowing helpers
    that raise `LiveNotArmed` (live executor). No `# type: ignore` was added.
40. **RUF009 is ignored** in `pyproject.toml`, because immutable `Decimal` defaults in frozen dataclasses are safe.
