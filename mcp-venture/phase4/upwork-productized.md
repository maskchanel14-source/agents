## Full description

**The problem this kills**

If you sell wholesale on Shopify without Plus ($2,000+/mo), your order desk probably looks like this: POs arrive by email (PDF, Excel, plain text), someone retypes every line into a draft order, checks prices against a spreadsheet, and chases net-30 payments from another spreadsheet. Real numbers from merchants I've talked to: 10–20 minutes per order, ~5 hours/day at 60 orders/day, and SKU/case-pack/price keying errors that cost goodwill.

**What I build (fixed scope, fixed price)**

An AI-powered intake pipeline on rails you own — no per-order SaaS fees, no app subscriptions:

1. **PO Pilot MCP server** connected to your Claude/ChatGPT/Cursor workspace — paste (or forward) any PO and get a **validated** Shopify draft order: exact SKU matching against your live catalog, price-mismatch flags, case-pack and inventory warnings, PO-number dedupe so nothing gets double-keyed, net-15/30/60 terms recorded, tags applied, invoice emailed with one command.
2. **Hands-off n8n automation** — a dedicated orders@ inbox watched 24/7: PO email in → AI extraction → catalog validation → draft order out, with a "⚠ NEEDS REVIEW" note on anything ambiguous. Your team approves; the machine types.
3. **Monday collections chaser** — weekly net-terms aging report + polite reminder emails pre-drafted for every overdue invoice. The "who owes me" spreadsheet dies here.

**Why me**
I build on Shopify's Admin GraphQL API (the same rails Shopify's own AI uses) and the Model Context Protocol — the open standard behind Claude and ChatGPT integrations. Everything is delivered as **your** code + **your** tokens: least-privilege scopes only (read catalog/customers/drafts, write drafts), nothing stored, MIT-licensed source you can modify forever.

**Requirements from you:** Shopify store (any plan) + admin access to create a free custom-app token (I walk you through it in 10 minutes), a sample of 3–5 real PO emails, your wholesale pricing rule (e.g. 40% off retail, or per-customer price lists).

**Guarantee:** if the pipeline can't intake your 5 sample POs end-to-end by day 5, you pay nothing.
