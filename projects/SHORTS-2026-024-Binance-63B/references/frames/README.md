# references/frames — reference capture

**This folder is intentionally empty.** PHASE 0 of the brief asks for 38
full-size (540×960) frames pulled from the reference channel's 20 latest shorts,
plus 1200 contact-sheet frames in `references/sheets/`. That needs YouTube
access, and this sandbox has outbound network to `npmjs.org`, `pypi.org` and
`github.com` only — nothing else resolves.

I did not fake it. Below is exactly what to run on a machine with network
access; it produces the layout the rest of the pipeline expects.

## 1. Download the reference shorts

```bash
# 20 latest shorts from the channel, best single-stream mp4
yt-dlp -f "bv*[height<=1080]+ba/b" \
  --playlist-end 20 --download-archive seen.txt \
  -o "references/source/%(upload_date)s_%(id)s.%(ext)s" \
  "https://www.youtube.com/@CHANNEL/shorts"
```

## 2. Extract the contact sheets (PHASE 0)

60 frames per short, tiled 6×10 into one sheet each:

```bash
mkdir -p references/sheets
for f in references/source/*.mp4; do
  name=$(basename "$f" .mp4)
  ffmpeg -i "$f" -vf "fps=2,scale=180:320,tile=6x10" \
         -frames:v 1 "references/sheets/${name}.png"
done
```

## 3. Extract the 38 full-size reference frames

```bash
mkdir -p references/frames
i=0
for f in references/source/*.mp4; do
  dur=$(ffprobe -v error -show_entries format=duration -of csv=p=0 "$f")
  for k in 0.10 0.55 0.90; do        # 3 frames × 20 shorts ≈ 60; keep the best 38
    t=$(awk -v d="$dur" -v k="$k" 'BEGIN{printf "%.2f", d*k}')
    ffmpeg -ss "$t" -i "$f" -frames:v 1 -vf "scale=540:960:force_original_aspect_ratio=increase,crop=540:960" \
           "references/frames/$(printf '%02d' $i)_${k}.png"
    i=$((i+1))
  done
done
```

## 4. Then re-run the 7 QA agents

With real frames in place, the reports in `references/reports/` should be
regenerated by comparing `stills/` against these frames. The reports currently
in that folder were written against numbers measured from our own render with
`media-production/scripts/analyze_frame.py`, which is objective but not a
side-by-side — see the note at the top of each report.
